# 📊 Data Analysis Projects — Python

## 📌 Overview
Collection of 6 end-to-end EDA (Exploratory Data Analysis) projects using Python across different domains.

## 🛠 Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)
- Jupyter Notebook

## 📁 Projects

### 1. 🛒 Superstore Sales Analysis
- Retail sales EDA — data cleaning, transformation, visualization
- Identified top-performing categories, regional trends, profit patterns

### 2. 🚗 Car Dekho Price Analysis
- Used car pricing data analysis
- Key factors affecting resale value — brand, year, fuel type
- Price distribution and depreciation trend visualizations

### 3. 🏠 Airbnb Booking Analysis
- Hotel booking pattern analysis using interactive Plotly charts
- Seasonal trends and pricing insights

### 4. 📉 Unemployment Analysis — India
- India unemployment trends analysis
- Regional patterns and COVID-19 impact on employment

### 5. 🏥 Healthcare Analytics — Doctor Visits
- Patient visit pattern analysis
- Health factor correlation study

### 6. 🌍 Global Terrorism Patterns & Trends
- Geographic and time-based terrorism data analysis
- Pattern identification using Seaborn visualizations

## 💡 Skills Demonstrated
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization (Matplotlib, Seaborn, Plotly)
- Statistical Analysis
- Business Insight Generation
